3. Critérios de auditoria

Uma carga do dia é selecionada para auditoria quando os dois critérios são atingidos ao mesmo tempo: o cliente precisa estar no percentual mínimo de ocorrências E a carga precisa atingir o valor mínimo. Para usar apenas um critério, deixe o valor mínimo em R$ 0 (nesse caso, só o % de ocorrências é exigido).
